# ScopePay — 90-Second Demo Video

## What the video must prove

ScopePay is a working USDC milestone escrow on Arbitrum Sepolia. The video should make three facts impossible to miss:

1. A Client funded a real smart contract with test USDC.
2. A Worker submitted a milestone and received payment after approval.
3. A Client opened a dispute and the named Arbiter settled it onchain.

Target length: **90 seconds**. Maximum working limit: **2 minutes**.

## How to record on Windows 11

Use Microsoft Clipchamp so the screen, microphone, cuts, and captions stay in one free tool:

1. Open Start and search for **Clipchamp**.
2. Select **Create a new video**.
3. Choose **Record & create → Screen**.
4. Enable the microphone and select the ScopePay browser tab or window.
5. Record each clip separately. Stop after each section; mistakes are easier to replace this way.
6. Drag the four clips onto the timeline in order.
7. Trim silence and wallet-loading delays.
8. Add the four on-screen text lines as short title overlays.
9. Enable automatic captions and correct the words `ScopePay`, `USDC`, and `Arbitrum` if necessary.
10. Export at **1080p MP4**.

If Clipchamp is unavailable, press **Windows + Shift + R** to record each screen clip with Snipping Tool, save the clips, and import them into any available editor.

## Free AI voice-over workflow

You do not need to record your own voice. After placing the four screen clips on the Clipchamp timeline:

1. Select **Record & create → Text to speech**.
2. Choose an English voice with a warm or neutral presentation style.
3. Set pitch to **Medium** and pace close to **0.95×**.
4. Generate one voice-over item for each clip rather than one long audio file. This makes timing and corrections easier.
5. Paste the four narration blocks below and select **Preview** before saving each one.
6. Place each generated audio item below its matching screen clip.
7. Shorten or extend each screen clip until its visual action ends with the narration.
8. Add automatic captions after the final voice-over timing is set.
